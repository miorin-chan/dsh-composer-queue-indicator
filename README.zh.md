# 排队发送提示

[English](README.md)

智能体运行中，如果按 Enter 会把草稿加入队列，发送按钮会显示「上箭头加两道横线」。
按住 Cmd 或 Ctrl 时，图标预览 **Mod+Enter** 的互补动作，松开后恢复默认图标。
鼠标点击仍使用原生默认发送方式，即使按住修饰键也一样。
插件不改变快捷键。

需要 DeepSeek Harness `0.2.2-rc.5` 的 Web 客户端。
在会话模块化改良计划中启用 **排队发送提示** 即可。
若要单独安装，在源码目录运行 `npm ci` 后，从 **插件 → 添加插件** 选择此目录。
两种安装方式任选其一。
