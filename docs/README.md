# 项目文档

插件通过 `conversation.input.overlay` 提供一段作用于当前 composer 卡片的局部样式。
样式匹配处于可用状态且原生无障碍名称为 `conversation` 命名空间 `input.send.queue` 的主按钮。
这是原生输入框已经计算好的排队状态，插件不复制其发送策略。
按钮没有独立的图标插槽，因此样式依赖 DSH `0.2.2-rc.5` 的 `InputBar` DOM 结构。
找不到按钮或本地化标签不可区分时，保留原生图标。

运行 `npm test` 和 `npm run check` 校验插槽注册、停用后的清理、文案定位和转义。
升版时，在实际会话中核对排队草稿、插话、空稿停止、命令、等待文件上传、发送中及继续生成。
也要核对语言切换、窄屏、深浅主题、休止符和单独停用这两个插件。
